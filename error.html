Varieties, Errors, and more!

In this page I am only discussing stamps. Before starting the topic of errors and verities, I want to classify items into the following groups:

Roughtly, all stamps fall into one and only one of these categories: 1 - issued: Ordered by postal authorities to be used in in the postal system and they were used in the postal system 2 - unissued: Ordered by postal authorities to be used in the postal system but they were never used in the postal system 3 - for collectors: Ordered by the official order of postal authorities for collectors 4 - forgeries: Any stamp that is not created by the official order of postal authorities Sometimes, a subset of stamps looked different from what it should look like. If the difference was acceptable by the postal authorities, it is called a "variety". If the difference was considered unacceptable and the authorities tried to prevent the stamp with such flaw to go into circulation, it is considered an "error". The three main characteristics of errors: - consistent: the difference appears on every stamp that went through the same process that caused it. - major: the difference should significantly impact the appearence of the stamp - unintentional: the difference should not be created by the postal authorities on purpose. There is a groupf of stamps that are created by or with collaboration from the postal authorities for collectors. If these stamps were supported by Iran Postal Service then these items should be considered philatelic stamps. If they are created by a postal authority for personal benefits, they should be considered forgeries.
